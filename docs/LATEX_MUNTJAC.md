# 胶液麂 / Latex Muntjac

- 实体：雄性 `changed_synergy:latex_muntjac`，雌性 `changed_synergy:latex_muntjac_female`。
- 兽化形态：雄性 `changed_synergy:form_latex_muntjac/male`，雌性 `changed_synergy:form_latex_muntjac/female`，均可从原生出身档案选择。旧版形态 ID 作为兼容别名保留；合成台沿用主模组的雌雄配方规则。
- 阵营：Light 下的丛林种群。种群身份由物种标签指定，移动到其他环境不会改变归属。
- 自然刷新：`minecraft:is_jungle` 标签覆盖的丛林、稀疏丛林和竹林，雄雌各权重 4，每组 1～2 只，总权重仍为 8。沿用胶液鹿的陆地生成条件、难度与环境限制。
- 属性与兽化：直接继承主模组 `LatexDeer` 的生命、攻击、护甲、移动、游泳属性和复制型兽化行为。
- 掉落：雄雌均引用胶液鹿的原生掉落表，保留草、皮革及抢夺附魔的计算。
- 物品：刷怪蛋及对应的纯胶液注射器、胶液锥形瓶、胶液箭；兽化物品放入各自的物品分组，使用主模组的形态数据与配色系统。
- 装备：雄性复用胶液鹿护甲模型，雌性复用主模组女性护甲模型；均接入配饰、Curios、面罩与披风渲染。
- 合成：在胶液合成台放入胶液基质、白胶液、丛林树叶、竹子和皮革，使用原版性别切换按钮决定注射器、锥形瓶或胶液箭对应的雄雌形态。不会获得白胶狼的切换性别能力。
- 被动蓄力跳跃：短按跳跃键，松开时普通起跳；按住约 0.15 秒进入蓄力，松开释放。无需连按。可以在空中按住，落地后开始计时；在空中松开会取消。蓄力时经验条临时显示原版马的蓄力条，再蓄力约 0.5 秒达到峰值，继续按住后维持约八成；满蓄力时基础起跳速度为普通跳跃的两倍，跳跃提升效果照常计算。雄雌均适用，人类玩家控制麂的包裹身体时同样生效。失去控制、变形、开菜单、进入水中或乘坐载具时取消蓄力。

## 模型来源与动作

雄性使用 `outputs/muntjac-20261024`，雌性使用 `outputs/muntjac-female-20261024` 内已有的 Java 模型导出和 128×128 材质；原始工程、导出文件与材质保持不变。雌性保留独立发型和躯干，并移除雄性角与犬齿。

行走、游泳、擒抱与尾巴由主模组的鹿类动画预设驱动。耳朵保留作者制作的直立展开角度，并使用导出包中的独立耳部弹簧；不叠加狼耳初始化动画，避免覆盖耳朵位置和角度。
