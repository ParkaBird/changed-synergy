# 胶液斑鬣狗 / Latex Spotted Hyena

- 实体：`changed_synergy:latex_spotted_hyena_male`、`changed_synergy:latex_spotted_hyena_female`。
- 形态：`changed_synergy:form_latex_spotted_hyena/male`、`changed_synergy:form_latex_spotted_hyena/female`。沿用主模组雄雌配对规范，可在原生出身档案选择。
- 阵营：Light 下的热带草原种群，离开原生环境或保存重载不会变更归属。保留普通胶兽社交、朋友、羁绊、据点、追逐和擒抱机制。
- 体型：雌雄碰撞箱均为 0.6×1.93 格，可通过营地的单扇木门与两格高入口；雌性较高的视觉模型保持原样。
- 属性：雄性沿用 Changed 狼类陆地形态的基础属性，生命 24、移动属性 1.075、跳跃力度 1；雌性生命 26、移动属性 1.13（约快 5%）、跳跃力度 1.05。NPC 与玩家兽化形态均生效。两者攻击 3、护甲 4、游泳属性 0.95；复制型兽化。
- 啃骨特性：雄雌玩家形态可按住使用键咀嚼原版骨头，1.6 秒后消耗一根，恢复 2 点饱食度及少量饱和度，随机获得 8 秒速度、急迫、力量、抗性提升或生命恢复 I。满饱食度仍可食用；创造模式不扣除物品；中断或变为其他物种不获得效果。受控的鬣狗包裹身体也可使用。普通人类和其他物种不能食用，骨头不被全局改为食物。受伤的朋友和羁绊可沿用自动进食机制食用背包里的骨头；据点成员也可在现有聚餐中选择骨头。仍遵循原进食配置、冷却和重伤优先包裹规则，不新增抢占任务的目标。
- 刷新：丛林与热带草原系列群系各加入雄雌权重 4、每组 1–2 只，总权重 8。`hyena_hideout` 与三种 `hyena_camp_*` 生成固定居民：小营地各 2 雄，藏身处 4 雄 1 雌；结构范围仅自然补刷雄性，居民不会自然消失。其他群系仅在这些建筑范围内提供鬣狗刷新，不对整个群系添加刷新项。仍遵循 Changed 的陆地、地表、难度、光照以及原版生物上限与玩家距离限制。
- 掉落：引用主模组鬣狗人马的腐肉与皮革掉落表，保留数量与抢夺附魔计算。
- 物品：雄雌刷怪蛋、对应的注射器、锥形瓶与胶液箭，使用原生图标及鬣狗配色，位于各自物品分组内。
- 胶液合成台：胶液基质、白胶液、金合欢树叶、骨头、兔子皮；原版性别按钮切换产物雄雌，不获得主动切换性别能力。
- 模型：使用用户提供的雄性工程与更新后的雌性工程，原文件不改动。128×128 嵌入贴图直接提取，保留雌性的独立体型与发型。预览用眼睛不导出，游戏内眼睛使用 Changed 的动态眼睛层，雌性的眼睛和头部配饰围绕头部枢轴放大，低头时保持贴合。
- 动画：复用主模组趾行人形的行走、游泳、装备和抓取链条，以及 Synergy 的平滑抬手、放手。耳朵使用与麂相同的逐实体弹簧，起落时俯仰、剧烈转头时滞后回弹，固定耳形由独立子节点保留；尾巴静态弯曲与动态摆动分层，避免预设覆盖模型角度。
- 配饰：接入 Changed 装备、披风、防毒面具、外骨骼与可选 Curios 槽位。物种本身不依赖 Addon Plus。

`tools/import_spotted_hyena_models.py <模型文件夹>` 重新提取贴图并导出几何；`tools/spotted_hyena_models_manifest.json` 记录原模型哈希。结构作者仍为 Crossader，原结构及其剧情内容不改动。

行猎装使用同一个物品按雌雄自动适配；新自然生成及建筑居民默认有 25% 概率穿戴，可通过 `HyenaTrailclothSpawnChance` 调整。详见 `HYENA_TRAILCLOTH.md`。

雄雌模型已同步 2026-10-30 提供的新版工程：眉毛改由嵌入贴图表现，不再保留旧眉毛方块或颜色覆盖。骨架、耳朵随动、动态眼睛与服装适配继续沿用现有机制。
