# 胶液剑鱼 / Latex Swordfish

- 实体：`changed_synergy:latex_swordfish`。
- 兽化形态：`changed_synergy:form_latex_swordfish`，可以在原生出身界面选择。
- 阵营与生活：水生阵营、远洋类型。使用现有海中捕食和水下储藏行为，自然刷新在深海生物群系的开放水域，昼夜均可生成。生成位置需低于海平面至少六格，脚下也需有水；和平难度不生成。权重为5，每组1～2只，不再叠加低亮度和额外1/40概率检查。
- 基础数值与生理：沿用主模组胶液鳗鱼的生命、攻击与护甲属性，包括24点生命和鳃；游泳属性从1.48提高至1.85（提高25%）。玩家形态与NPC均使用该属性。
- 兽化物品：沿用主模组的纯胶液注射器、胶液锥形瓶和胶液箭，写入剑鱼形态数据，按剑鱼配色显示。物品列在各自类别中；另有剑鱼刷怪蛋。

## 剑鱼突进 / Swordfish Rush

仅在水中可用，按住能力键蓄力半秒，每次消耗半格饱食度（创造模式不消耗）。初始推进量与二级激流相同，沿发动时的视线方向突进，动作最长持续一秒；减速至正常游动速度、碰撞或出水时提前结束，随后在两刻内恢复游泳姿态。玩家冷却三秒，NPC 冷却四秒；NPC 留在水中也能再次突进，目标靠近后仍可发动。

沿用游泳动作的定位，快速过渡到挺直身体，头与剑吻沿冲刺轴朝前，并附带激流的身体旋转、水流特效、气泡和去掉投掷起音的激流音效，结束后自然恢复游泳。镜头不强制翻滚。撞击敌人造成8点基础伤害，按目标一半护甲计算减伤；韧性、护甲耐久、防护附魔、抗性效果和盾牌依然生效。每次突进对同一目标最多结算一次，保留原版伤害事件与友方保护。墙后的目标不会被命中。NPC仅在战斗中对可见目标发动突进。

## 模型来源

使用 `outputs/swordfish-20261022/UnifiedLatexSwordfish.bbmodel` 中的17个骨骼、36个方块与内嵌128×128纹理，包含更新后的剑吻配色和剑根过渡部件。行走、游泳和尾巴由主模组水生动画驱动，突进时平滑收拢游泳摆动。原始工程保持不变。选角档案头像略转18度，以显示头顶的面片鳍。

导出的静态方块节点使用主模组识别的 `*_rN` 名称，使兽化过渡可以合并未旋转的几何节点。在安装 EMF 与玩家动画资源包时，仍需验证第一人称双臂、全身过渡及兽化存档重载，不能只验证最终形态的渲染。

## 蚕蛾趋光

NPC蚕蛾空闲时会寻找附近明亮、可站立且能够安全抵达的位置，靠近后稍作停留。跟随、据点任务、战斗、救援和社交互动优先。搜索沿用后台预算且不加载新区块。

普通游荡的优先级低于安全光源停留；地面按上表面能否承重判断，包含玻璃地面。搜索使用独立五秒冷却与共享后台预算，避免目标选择器的检查频率与固定扫描相位错过。

目标与路径节点排除火、灵魂火、岩浆、点燃的篝火和灵魂篝火、岩浆块等危险。停留位置附近出现危险或光源熄灭时结束这次行为。
