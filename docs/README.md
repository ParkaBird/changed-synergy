# Changed: Synergy 1.1.4 — Player guides

These guides describe the default 1.1.4 rules. A server can change gameplay settings; check its settings page when an option behaves differently.

**Recommended pairing:** Synergy 1.1.4, Changed 0.15.7 and TrueTransfur 2.0.0. TrueTransfur is optional for NPC relationships and camps. Its 2.0.0 version requires Mixin Args on both server and clients. Native origins also support TrueTransfur 1.0.1; the separate Instinct body and expanded Instinct interactions require 2.0.0.
