# Changed: Synergy 1.1.5 — Player guides

Start with the community guide for Beta.2's household life and admission system, or choose another topic below. A server can change gameplay settings; check its settings page when an option behaves differently.

**Supported pairing:** Synergy 1.1.5-Beta.2, Changed 0.15.7 and TrueTransfur 2.x. TrueTransfur is optional for NPC relationships, community membership and camps. Native origins, permanent dialogue rituals and Instinct require it; its 2.x integration requires Mixin Args on both server and clients. TrueTransfur 1.0.1 compatibility is no longer maintained or tested.
