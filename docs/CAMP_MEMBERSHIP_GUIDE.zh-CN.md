# 营地社区与入会玩法指南

适用版本：**Changed: Synergy 1.1.5-Beta.2**。本指南介绍社区入会、贡献和日常玩法；服务器设置可能影响可用功能。

## 先体验一次完整的社区生活

1. 找到森林树屋、鬣狗藏身处、天文台或沙漠避难所，向当地首领发起“对话”。
2. 听听这里的经历和生活规矩，选择加入；保持人类身体也可以。
3. 打开关系名册，认识带有“同营”标识的邻居。
4. 问问营地近况，把想分享的物品拿在主手，通过对话捐赠。
5. 接一项请求，分清它要交给首领还是某位居民。
6. 邀请大家吃饭、补充睡位、照料作物，慢慢提高这里的本地信任。

不需要每天上线维护，也不用为了留在社区而接受兽化。拒绝请求、外出探索或暂时离开都不会自动扣信任。

## 社区、据点和阵营的区别

| 地方或关系 | 你在其中的身份 |
| --- | --- |
| 自然生成的社区 | 建筑和居民本来就在这里；你向首领申请，成为这个小团体的成员 |
| 玩家据点 | 由玩家建立和安排同伴工作的据点，沿用自己的管理与绑定机制 |
| 野外胶兽据点、小营地 | 保留各自的居民活动、交易和容器规则，不一定提供正式入会 |
| 地区阵营 | 跨建筑的声望与外交关系；与某一社区的本地信任分别记录 |

正式入会目前覆盖**森林树屋、鬣狗藏身处、天文台和沙漠避难所**。加入一座树屋，只代表加入这一座树屋的家庭，不代表所有森林胶兽都成了你的同营成员。鬣狗小营地、绿洲、泥地营地和实验室不提供同一套入会流程。

## 找到社区与首领

| 社区 | 所在群系 | 首领 | 本地信任奖励服装 |
| --- | --- | --- | --- |
| 森林树屋 | 森林 Forest | 织匠 Weaver（蚕蛾） | 巡林装 Ranger Outfit |
| 鬣狗藏身处 | 热带草原 Savanna | 女族长 Matriarch（斑鬣狗） | 行猎装 Trailcloth Outfit |
| 天文台 | 积雪山坡 Snowy Slopes、雪林 Grove | 档案员 Archivist（雕鸮） | 飞行服 Aviator Outfit |
| 沙漠避难所 | 沙漠 Desert | 领路人 Pathfinder（跳鼠） | 沙行装 Wayfarer Outfit |

这些社区都是稀有地标。探索地图可能出现在相应群系的部分战利品箱中：森林瞭望塔可以提供线索，热带鬣狗小营地可能指向藏身处，山地相关箱子也可能找到天文台地图；绿洲、泥地营地和部分沙漠、恶地战利品箱可能提供沙漠避难所地图。地图不是每箱必出。

绿色实验室的研究员也有独立对话，偏向经历、研究和趣事；他不是首领，不办理社区入会。

四位首领有各自的生活与性格：织匠沉着而有礼貌，女族长护短而有礼貌，档案员好奇而有礼貌，领路人谨慎而有礼貌。书、便笺和剪切板补充他们的经历，可以先读再聊。更深入的第三项背景话题，会在前两项完成后开放。

## 怎样交谈

靠近对方，从社交轮盘进入“对话”。首领的个人故事和社区事务都从交谈中展开；普通同营居民的“聊一聊”也会进入社区对话。

口语逐字呈现；符合既有理解条件时，心语与正文一起显示，带有横线和整句淡入。交谈不会直接解锁心感能力。四位首领都学会了人类口语，人类也能了解入会与请求。

点击或按 Enter，先补全当前段落，再继续。正文显示完成后，按键提示与选项会一起出现。选项出现后可用方向键与 Enter 操作，Esc 离开。世界不会暂停；战斗、距离过远等情况会中断会话。NPC 正与别人交谈时，请稍等。

## 入会与身体选择

本地信任达到 **0 或以上**、没有当前敌意、首领没有正忙于战斗时，可以申请。你同时只能登记一个正式的家。

| 入会方式 | 身体与身份 | 本社区入会信任额度 |
| --- | --- | --- |
| 保持人类身体 | 不改变身体和原有出身 | 0 |
| 保持已有胶兽形态 | 不改变现有身体 | 2 |
| 可逆兽化仪式 | 获得首领提供的形态；此次明确选择的仪式保留逆转资格 | 5 |
| TT 永久兽化仪式 | 成为对应物种的原生胶兽，采用 Native Origin 的身份与身体规则 | 8 |

可逆仪式不改动野外兽化规则，也不能把原本永久的身体变成可逆。解除仍需要可用、获准的逆转方式。处于包裹、接管、已有原生身体等状态时，相关仪式可能不会出现；可以保持现状加入。

**永久仪式需要 TrueTransfur。** 首领会再次说明后果，只有二次确认后才执行。成功后会有正常兽化音效。`/untf`、`/untransfur` 等普通逆转会在移除身体前被拦截，不会先变人再恢复。离开社区不会解除原生身体。

如需重新选择人类，须通过服务器允许的 **Native Origin 重选**。管理员可用 `/changedsynergy origin choose <玩家名>` 打开档案；需要相应权限，且原生开局规则已开启。确认人类后会安全恢复人类身体，取消则保留原身份。社区归属、信任、个人关系与领奖记录不清空。`/changedsynergy origin` 可查看自己的身份。普通入会不要求管理员操作。

入会信任按同一玩家、同一社区已经取得的最高额度补差：先以人类加入，之后符合条件并选择可逆仪式，可以补到 5；退出重加不会重新领取。已有永久仪式记录会迁移为原生身份，不会重复发奖。

## 认识居民：四种关系分别记录

| 关系 | 作用 |
| --- | --- |
| 本地信任 | 属于这一处社区，决定共享待遇与社区奖励 |
| 个人好感 | 属于某位居民，记录你们之间的交往 |
| 羁绊 | 仍按原有羁绊条件建立，提供对应的同伴互动 |
| 地区阵营声望 | 用于地区范围的外交与社会反应，不等于社区信任 |

正式加入会介绍社区内置居民，并为每位居民各增加 **1 点好感**，每个个体只介绍一次。尚未加载的居民之后加载、且你在线时会补上介绍。关系名册用“同营”标识当前社区成员；居民也与你建立羁绊时，两种标识并列显示。

普通居民可以同时是同营伙伴、朋友或羁绊同伴。明确跟随主人时优先跟随；回家并恢复自由活动后，可以继续社区日常。固定首领保留亲密互动，但不开放羁绊随行与身体接管。

## 公共储备、私人东西和故事载体

每处正式社区有一组指定的 **“社区公共储备”** 双箱。居民的公共食物、采集与狩猎收获、拾取物和玩家贡献都集中到这里；战利品箱不会因为被打开过就变成公共储备。

本社区待遇正常的成员可以共享公共储备。居民只从这组储备取用公共物资，也只把活动收获存入这里；箱子满了或暂时不可用时，会保留携带的东西，不会改用别人的箱子。

标记为私人的箱子和其他储物容器不属于公共储备。同营也需要尊重隐私：附近清醒、能看到你翻找的居民会警告；短时间内反复翻动，会按冷却扣除本地信任。**单纯翻找这些私人容器不会触发储物防卫攻击**，但砸坏容器、攻击居民等是另外的行为。

讲台和其他可阅读的剧情载体开放阅读，不会仅因阅读触发警告。明确放在私人箱子里的物品仍受该箱子的隐私规则约束，角色默认装备也不会变成公共物资。访客翻动其他受保护储备、破坏箱子或侵犯野外据点，仍可能引起防卫。

## 了解近况与贡献

问首领“营地最近怎么样？”一类选项，可以了解食物、空闲睡位、安全、请求和自己的成员待遇。居民偶尔会主动靠近招呼，邀请你交谈，不会强行打开界面。如果听不懂普通居民，可以请首领说明社区事务。

### 分享物资

把物品拿在主手，通过分享物资的选项确认交付。可接受类别包括适合居民的普通食物、羊毛、皮革、纸和火把，数量与需求以当次对话为准。系统检查主手物品、数量和箱子空间，接受后才转移。自定义命名物品、角色绑定装备等不会当成普通捐赠收走。

直接把东西放进公共箱可以补充储备；想登记贡献或完成交付请求，应使用对应对话。借出的公共物资再交回来会先计作归还，不会循环产生捐赠奖励。

### 公共请求与个人请求

| 类型 | 找谁交付 | 物品去哪里 |
| --- | --- | --- |
| 公共物资请求 | 首领 | 社区公共储备 |
| 个人请求 | 提出请求的居民 | 该居民的个人物品栏 |
| 保护请求 | 实际帮助应对威胁后，安全时回来报告 | 依据实际援助记录结算 |

树屋的公共请求常与羊毛有关，藏身处与皮革有关，天文台与纸有关；缺粮时也可能请求食物。交付时拿齐对话要求的数量。个人请求不占用公共箱空间。

公共请求是全社区共享的，个人请求属于对应居民；其他玩家可能先一步完成。当前请求没有倒计时，阅读也不会独占它。完成后的请求可能在之后的游戏日更新。拒绝、以后再做或离开不会扣分。

保护居民不等于随意猎杀。实际应对威胁后，等社区安全再回来；不必主动引怪，更不要把营地内养殖的动物当猎物。

### 怎样积累本地信任

| 帮助 | 常见信任收益 |
| --- | --- |
| 有效的新物资捐赠 | +1 |
| 完成物资请求 | +2 |
| 被居民看到收获成熟作物，并及时在原位补种 | +1 |
| 实际帮助保护居民 | +2 |

这些贡献收益对同一玩家、同一社区，每个服务器游戏时间日最多 **8 点**。睡觉跳过夜晚或上下线不会单独重置额度；同一次保护不会在报告时重复结算信任。好感与信任分别变化，别把两种数字混为一谈。

正常成员的本地信任达到 **40** 后，可以向首领领取该社区服装。每位玩家、每个社区领取一次；退出重加不会刷新。背包放不下时不会消耗领取机会。

## 居民每天怎样生活

社区居民围绕自己的建筑活动：采集和拾取物资、收获并补种作物、狩猎附近野生猎物、用餐和休息。他们保护内置的养殖动物，不会为了另建一个据点而离家。普通居民可以在建筑外附近活动，活动边界保留约六格余量；首领保留建筑范围内的活动约束。

成员可以通过对话邀请大家吃饭。社区安全、公共箱里有合适食物、指定用餐点可用时，有空的居民会聚过来。有篝火的社区需要点燃篝火；沙漠避难所使用自己的聚餐点，不要求篝火。玩家自己决定是否过去坐下或吃东西，不会被传送入座。居民休息时会优先考虑可坐物体，再考虑地毯，最后才是普通空地。

居民在结构范围内寻找适合自己、可到达且未占用的睡位，包括玩家后来摆放的床。符合条件的鸟类居民有可用栖木时优先使用：立式一个位置，横式两侧各一个位置。雕鸮白天睡、晚上活动；其他物种按各自作息。野外未归属的胶兽不会因此随便找社区床睡。

成员可以使用空闲且适合身体的睡位，不能挤走正在睡觉的居民。**本地信任达到 40 的访客**也可借用；床与栖木本身的使用条件仍适用。玩家据点也能按原有绑定方式使用栖木。

## 维修和布置

- 公共储备登记后，即使被拆掉，在**原来那两格位置**补放普通箱子、组成可用双箱，也能重新识别。这个修复不会找回丢失物品。
- 睡位不要求必须来自原始结构模板。可以补床、换床，或在结构范围内为合适鸟类放栖木；留出通路和身体空间。
- 居民能开启路线上的普通门、木活板门和栅栏门，并在通过后关闭；铁活板门仍需红石。
- 新版本模板的箱子位置、私人标记和床铺调整不会覆盖旧存档建筑。已经登记的旧储备仍按自己的原位置识别，随意把箱子搬到别处不会自动迁移登记。

## 换家、退出和信任下降

向另一处首领申请会先要求换营确认；同一时间只有一个正式的家。确认前旧归属保持不变。若还选择永久仪式，身体变化仍需自己的二次确认。

想离开，可以在首领处谈自己的归属并确认退出。同营标识和本营成员待遇会结束，但个人关系、羁绊、本地信任、入会奖励记录与当前身体保留。之后可以回来探望或帮忙。不同社区的信任不会因为换营而互相复制。

本地信任降至 **−15** 会暂停成员共享待遇，恢复到中立后恢复；降至 **−40** 会被除名。伤害居民、反复侵犯隐私、破坏公共设施可能损害信任。单纯拒绝请求或外出不会产生这种惩罚。

## 找不到人或交不了东西时

| 情况 | 先检查什么 |
| --- | --- |
| 没有入会选项 | 对方是不是四位首领之一；是否战斗中、存在敌意或本地信任低于 0 |
| 没有永久仪式 | TT 是否安装并支持该机制；当前是否已经兽化、原生、被包裹或处于接管 |
| 想恢复人类 | 通过获准的 Native Origin 重选；普通 untf 不能解除原生身份 |
| 交付失败 | 主手物品与数量、请求是否已完成、公共箱或该居民的物品栏是否有空间 |
| 居民不聚餐或不睡觉 | 安全、食物、用餐点、物种作息、空位、通路，以及是否正处于跟随或其他任务 |
| 公共箱不识别 | 是否在该社区已登记的原位置、双箱两半是否完整；任意新箱子不是自动公共储备 |
| 首领暂时不见了 | 先查看其家园和活动区域；区块卸载不等于死亡，也不会凭空复制一个首领 |

固定角色确认死亡或真正失踪后，默认等待约 **20 分钟服务器游戏时间**尝试回归，需所在区域已加载且有安全位置，不会为此强行加载区块。关系与剧情进度保留，默认服饰不会重复掉落来供刷取。

服务器与客户端应使用对应版本；具体开关、权限和模组组合以服务器为准。

## 小营地与研究员

绿洲、泥地营地和三个鬣狗小营地各自管理居民补给和日常活动，没有首领或正式入会，也不会与大社区远程共用库存。它们使用原有容器作为居民补给；这些容器对玩家仍属于私人存储。居民会取用补给，也会存入活动收获。每名小营地居民出生时有 25% 概率穿着对应服装，只判定一次。

加入一个大社区不会自动获得附近小营地的成员身份或存储权限。小营地和部分相应群系的战利品有机会提供指向大社区的地图。

绿色实验室的研究员提供个人对话，不负责招募。他会休息、使用合适的床和座椅，并吃自己携带的食物，不会采集、狩猎或取用实验室战利品。

## 服务器设置

社区对话、日常活动、友谊、心感和原生身份功能受服务器设置控制。No Civilization Mode 会限制声望与本地信任收益，也会影响信任奖励的取得。符合常规条件却没有对应选项时，可以询问服务器管理员；普通入会、贡献和居民请求不需要管理命令。

自己建立并安排工作的营地，另见[玩家据点指南](PLAYER_CAMP_GUIDE.md)。设置与命令见[服务器配置](SERVER_CONFIGURATION.md)。[English guide](CAMP_MEMBERSHIP_GUIDE.md)。
